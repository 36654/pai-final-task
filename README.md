# 積み木のお片付け: ACT と SmolVLA の比較(Physical AI 応用編 最終課題)

CRANE+ V2 の模擬ロボット(Gazebo + ROS2)で、積み木を箱に入れる動作を模倣学習し、2つの方策 **ACT**(言語指示なし)と **SmolVLA**(VLA。言語指示あり)を同じ配置・同じ基準で比べた記録とコードです。シミュレーションのみで、実機は使っていません。

## 1. 結果(結論)

| 段階 | 条件 | ACT | SmolVLA |
|---|---|---|---|
| 段階1 | 積み木1個(赤)・20配置 | 12/20 (60%, 95%区間 39〜78%) | 18/20 (90%, 70〜97%) |
| 段階2 | 積み木2個(赤・青)・指示は赤(条件A。ACT は指示なしで、赤が入ったかで採点) | 1/10 (2〜40%) | 8/10 (80%, 49〜94%) |
| 段階2 | 積み木2個(赤・青)・指示は青(条件A) | 0/10 (0〜28%) | 6/10 (60%, 31〜83%) |
| 参考 | 黄色が対象・赤が妨害物(条件B。黄色は未学習の色) | 0/10 (0〜28%) | 5/10 (50%, 24〜76%) |
| 参考 | 積み木1個(青)・未学習の条件(条件C) | 8/10 (49〜94%) | 5/10 (50%, 24〜76%) |

- 段階2はすべて、指先の摩擦係数 1.5、同じ PC・同じ配置(seed 2000、10配置)で測った。
- 条件Aは、赤・青とも ACT と SmolVLA の95%区間が重ならない。条件Cの差(ACT 8/10、SmolVLA 5/10)は、区間が重なり確定しない。
- 専門家(ルールベースのデモ生成)の成功率は、決めた範囲内で 159/161(約99%)。
- 段階1の差(ACT 60%、SmolVLA 90%)は、信頼区間が重なるため確定しない(20回の試行)。
- グリッパを閉じた瞬間の腕の向きを調べた(条件A)。SmolVLA は、指示した色の積み木の近くで閉じた(20回中18回が12度以内)。ACT は2個の積み木の中間付近で止まり、10回中9回は閉じなかった。
- ACT は言語指示を受け取れないため、積み木が2個になると対象を選べない。
- 段階2のSmolVLA は、学習データの作り方を変えて3回学習した(`s2_color` → `s2_pair` → `s2_mix`)。条件B・Cは学習データにない場面で、参考値として扱う。
- 途中まで指先の摩擦係数が 0.2 のまま測っていたため、段階2は 1.5 で測り直した。以後、評価とデモ生成の起動時に環境を自動で確かめる(`tools/env_gate.py`)。
- 成功の定義: 開始から30秒以内に、積み木が箱の中に入る。積み木は5 cm の立方体、箱は内寸12 cm・縁の高さ6 cm。

## 2. 方法

1. **デモ生成**: 位置情報を使うルールベースの専門家が、積み木と箱の配置(積み木 θ −90〜−30°・距離 8〜12 cm、箱 θ +30〜+80°・距離 12〜18 cm、積み木の向き ±30°。段階2は積み木の θ −112〜−30°・距離 8〜12.5 cm に広げた)をランダムにして、デモを自動生成する。
2. **学習**: ACT と SmolVLA(`smolvla_base` を微調整)を、LeRobot 形式のデモから模倣学習する。学習は Google Colab(A100)。
3. **評価**: Gazebo で、同じ配置(乱数 seed 2000。学習データとは別の配置)・同じ30秒の制限で成功率を測る。SmolVLA は Colab の GPU を推論サーバーにして、PC の Gazebo から呼ぶ。推論中は Gazebo を一時停止する。

AI が見るのは天井(俯瞰)カメラ 1台(320×240、20 Hz)と関節角。正面カメラは録画専用。

## 4. 再現の流れ(概要)

前提: 講座が提供した Docker 環境(`pai_ros2`。ROS2、Gazebo、CRANE+ V2 のパッケージを含む)。

1. `setup_machine.bat` で環境を初期化し、Gazebo を起動する。
2. `expert_episode.bat` でデモを生成し、`make_dataset.bat` で LeRobot 形式にする(段階2は `stage2_gen_WRITE.bat`)。
3. `tools/colab/` のノートブックを Colab で実行して学習する。
4. `eval_act.bat`(ACT)、`stage2_eval.bat`(段階2)で評価する。SmolVLA は `tools/colab/smolvla_infer.ipynb` で推論サーバーを立て、`stage2_eval.bat vla URL TOKEN` を使う。

詳しい手順と注意点は `README.txt` に書いてある。
